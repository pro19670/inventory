## 📊 기능 흐름 요약

### 1. 이미지 인식 흐름
- `smart_camera_button.dart` → `item_classifier.dart` → `label_mapper.dart` → `add_item_dialog.dart` 자동 채움

### 2. 음성 명령 흐름
- `voice_input_button.dart` → STT → `command_parser.dart` → 물품 자동 처리

### 3. 추천 흐름
- 날씨 연동 → `outfit_recommender.dart`
- 보유 식재료 기반 → `grocery_recommender.dart`
- 결과는 `ai_provider.dart` → `ai_recommendation_card.dart`에 표시

### 4. 데이터 저장 흐름
- `inventory_provider.dart`로 상태 유지
- `data_storage.dart`로 SharedPreferences 또는 파일에 저장/로드
